# 阶段 04：分批扩展其余八题

现有 704 和 206 必须已经有真实执行与完整教学闭环。现在增加且仅增加：283、977、1、20、21、104、70、3。

主 agent 先列出共享适配器与渲染器缺口，冻结必要接口。每个工作 agent 获得明确的课程包目录、局部测试和允许修改的适配器/渲染器范围。公共入口、共享契约、package.json 和锁文件仍由主 agent 集成。

建议三个批次：
第一批：283、977、1，验证数组原地修改、返回新数组、哈希表。
第二批：20、21、104，验证栈、链表节点复用、树和调用栈。
第三批：70、3，验证状态递推与滑动窗口。

每批最多 3 个工作 agent；不要一次启动十个 agent，也不要同时修改同一个 renderer。独立内容可以并行，共享基础能力先实现、测试、集成，再让题目依赖它。

每题均交付 PRODUCT_SPEC 第 5 节的完整课程包，不允许“先放标题占位”。讲解需要呈现“为什么采用该结构或状态”，而非贴出答案逐句翻译。

特别检查：
283 判定原数组修改及非零次序；977 负数平方和从后填入；1 接受任意索引顺序并禁止复用同一元素；20 空栈和剩余栈元素；21 节点复用且不成环；104 层序 null 解析、空树与返回顺序；70 基例和较大有效 n；3 连续子串、空串、空格与左边界错误回退的反例。

每题的参考模型输出与实际 Java 参考解法做差分测试；每题至少 8 个有效用例、两个错误 Java 夹具和两个预测检查点。关键中间状态要有不变量断言，不接受只有最终图片快照的“算法测试”。

每批完成后主 agent 集成、运行相关测试并回归前两题；失败先修，不带着红色测试继续大量扩题。进度、源码版本、错误状态与编辑器仍复用同一套组件。

阶段验收：十题全部可进入、可学、可改、可真实执行；无假通过、空白详情页、未接通按钮或静态结果冒充动画。更新逐题矩阵和 STATUS，停止。
