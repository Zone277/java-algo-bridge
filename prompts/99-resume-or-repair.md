# 中断恢复或定向修复

先读取 AGENTS.md、PRODUCT_SPEC、STATUS、CONTRACTS、DECISIONS，再检查 Git diff、已有测试和真实环境。

不要从零重建项目，不更换框架，不覆盖用户改动，不只依据前次对话声称的完成状态。用文件和可重复执行结果确认当前位置。

找出上个阶段尚未通过的最小验收项。主 agent 指定独立审查/实现 agent 和互不重叠的写入范围，复现失败后做最小修复，并添加能防止同类问题复发的回归测试。

保留测试意图，不能靠删除测试、改成 skip、伪造接口成功、隐藏错误或放开容器限制解决问题。

运行受影响测试以及已有关键流程，更新 STATUS：实际问题、根因、改动文件、真实结果、剩余阻塞和下一阶段。

遇到环境阻塞时，给出准确检查与修复办法；可以完成不依赖该环境的任务，但不能把未验证功能标记完成。
